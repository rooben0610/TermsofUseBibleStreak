## 1. Who we are

## 2. Personal data we collect

Depending on how you use Bible Streak, we may collect the following categories of personal data:

### A) Account and identity data
- User ID (for example Firebase user ID)
- Sign-in details from identity providers (such as Sign in with Apple / Google Sign-In)
- Email address (where available)
- Display name / username
- Profile photo URL (if provided)

### B) App usage and device data
- App interaction events (for onboarding, feature usage, engagement, and conversion measurement)
- Device/app identifiers and technical diagnostics
- Push notification token(s)

### C) Subscription and transaction data
- Subscription status, trial status, entitlement status, product identifiers
- Purchase and restore metadata provided through Apple/RevenueCat integrations  
(We do not receive your full payment card details. Payments are handled by Apple.)

### D) User content and feature data
- Information you submit in app features (for example profile information, progress/streak information, social/friend connections, session metadata)
- Content you provide when using camera/photo-dependent app features, where applicable

### E) Advertising and attribution data
- Attribution and campaign data from analytics/measurement providers (for example AppsFlyer and TikTok Events SDK)
- If you allow tracking on iOS via App Tracking Transparency, identifier-based attribution data may be processed

### F) Permissions-related data
- Notification permission status
- Family Controls / Screen Time related selections and states used for app functionality (where enabled by you)
